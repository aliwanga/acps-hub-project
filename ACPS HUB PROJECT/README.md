# ACPS HUB Student Portal

Building smart solutions for better communities through technology and innovation.

A simple, offline-friendly student portal that runs in the browser with no installs.

## Features
- GPA calculator (4.0 scale)
- Exam, CAT and assignment reminders
- Weekly timetable
- Budget tracker (KES)

Data is saved only in your own browser (localStorage). Nothing is sent to a server.

## Run locally
Open `index.html` in any browser.

## Live site
After enabling GitHub Pages: `https://YOUR-USERNAME.github.io/acps-hub-project/`
